# Fridge — прогнозирование футбольных матчей

Ансамбль из статистических моделей и машинного обучения. Он прогнозирует исход матча
(П1/X/П2), ожидаемые голы, тоталы, «обе забьют» и точный счёт для 5 топ-лиг: АПЛ,
Ла Лиги, Серии А, Бундеслиги и Лиги 1.

## Быстрый старт

```bash
pip install -r requirements.txt
python -m football_predictor download        # ~60 тыс. матчей с 1993/94 по текущий сезон
python -m football_predictor backtest        # честная проверка на 5 последних сезонах
python -m football_predictor train           # финальная модель -> models/predictor.pkl
python -m football_predictor predict --league premier-league --home Arsenal --away "Man City" \
       --date 2026-11-01 --odds 2.60 3.50 2.70
```

Пример вывода:

```
Arsenal — Man City  (premier-league)
  П1  41.4%   X  29.6%   П2  28.9%
  справедливые коэф.:  2.41 / 3.37 / 3.45
  ожидаемые голы: 1.33 — 1.14
  ТБ1.5 71.8% | ТБ2.5 44.8% | ТБ3.5 23.6% | обе забьют 51.2%
  вероятные счета: 1:1 (14.0%), 1:0 (10.1%), 0:0 (9.7%), 2:1 (8.5%), 0:1 (8.4%)
  П1 @ 2.60: EV +7.7%, ставка (1/4 Келли) 1.2% банка  <-- value
```

Другие команды:

* `predict --fixtures matches.csv --out preds.csv` — прогноз сразу для списка матчей
  (колонки `league,home,away[,date,odds_h,odds_d,odds_a]`);
* `teams --leagues la-liga` — названия команд и текущие рейтинги Elo;
* `--extra-csv file1.csv file2.csv` — добавить свои данные (подходит для любой команды).

## Как это работает

```
матчи по времени ──► движок признаков (состояние «до матча», без утечки будущего)
                       ├─ Elo (поправка на разницу мячей, откат к среднему между сезонами)
                       ├─ pi-ratings (отдельные рейтинги дома и в гостях)
                       ├─ Диксон–Коулз с затуханием по времени (переобучается каждую неделю)
                       ├─ форма (EWMA): голы, удары, удары в створ, угловые, очки
                       ├─ отдых, опыт в лиге, флаг новичка, средние по лиге
                       └─ рыночные вероятности без маржи (коэффициенты football-data.co.uk)
                                   │
          ┌────────────────┬───────┴─────────┬──────────────────────┐
     LightGBM-        логистическая     LightGBM Poisson        Диксон–Коулз
     классификатор    регрессия         (голы) → матрица счёта
          └────────────────┴───────┬─────────┴──────────────────────┘
                 смешивание с весами, подобранными на последних сезонах (min log loss)
```

Принципиальные моменты:

1. **Нет утечки данных.** Признаки каждого матча считаются только по матчам, сыгранным
   до него, и это проверяет тест (`tests/test_core.py`).
2. **Walk-forward валидация.** Каждый тестовый сезон предсказывается моделью, которая
   обучена только на прошлых сезонах. Ранняя остановка и веса ансамбля подбираются на
   двух последних сезонах из обучающих.
3. **Оптимизируются вероятности, а не угадывание.** Главные метрики — RPS и log loss.
   Модель хорошо откалибрована: ECE около 0.5%, то есть прогноз «60%» сбывается примерно
   в 60% случаев. Без калибровки нельзя искать value-ставки.
4. **Новички лиги** (обычно клубы, поднявшиеся из низшего дивизиона) стартуют с рейтингом
   слабее среднего, а не со средним.

## Результаты бэктеста

Данные — football-data.co.uk (5 лиг, 1993/94 — текущий сезон). Тест — сезоны 2022/23–2026/27
(текущий сезон — сыгранные на сегодня матчи), 7428 матчей, walk-forward.
«Рынок» — закрывающие коэффициенты (Pinnacle или среднее по рынку) без маржи: самая сильная планка.

| Модель | RPS ↓ | LogLoss ↓ | Точность | ECE |
|---|---|---|---|---|
| Рынок (закрытие) | 0.1944 | 0.9662 | 54.4% | 0.010 |
| Ансамбль + коэффициенты как признаки | 0.1944 | 0.9663 | 54.2% | 0.009 |
| **Ансамбль без коэффициентов** | **0.1984** | **0.9792** | 53.0% | 0.005 |
| Диксон–Коулз | 0.2013 | 0.9894 | 52.6% | 0.007 |
| Частоты исходов | 0.2309 | 1.0749 | 43.8% | 0.016 |

Выводы:

* Модель только на результатах и статистике матчей проходит ~85% пути от частот до рынка,
  но закрывающую линию не обыгрывает: ставить против неё по этой модели — в минус.
* Если дать модели коэффициенты, она сводится к рынку (веса ансамбля ≈ 100% на рынок):
  поверх закрывающей линии наши признаки почти ничего не добавляют.
* `backtest --no-market` — чистая модель против рынка, `backtest` — с коэффициентами.

## Этап 1: разведка АПЛ и планка букмекера

`python analysis/stage1.py` — АПЛ 2014/15–2023/24 (3800 матчей): доли исходов, голы, доля побед
хозяев по сезонам (`analysis/home_win_share.png`, в 2020/21 без зрителей — 38% против ~45%),
маржа Bet365 (в среднем 4.1%), log loss на 2023/24: наивный 1.0986, частоты 1.0542, Bet365 0.9092.

## Как сделать точнее

* **xG.** В текущем сезоне football-data.co.uk отдаёт xG (`HxG`, `AxG`) — они уже читаются
  (`hxg`, `axg`). Когда наберётся история, их стоит добавить в форму команд.
* **Составы, травмы** — главная информация, которой нет в данных, но есть в рынке.
  Новые признаки добавляются в `FeatureEngine.features()`.
* **Регулярно обновляться:** `download` всегда перекачивает текущий сезон, затем `train --rebuild`.

## Структура

| Файл | Что внутри |
|---|---|
| `football_predictor/data.py` | загрузка с football-data.co.uk, нормализация, коэффициенты |
| `analysis/stage1.py` | этап 1: разведка АПЛ и бенчмарк букмекера |
| `football_predictor/features.py` | Elo, pi-ratings, форма, Диксон–Коулз — последовательный движок признаков |
| `football_predictor/dixon_coles.py` | модель Диксона–Коулза, матрица счёта, рынки |
| `football_predictor/model.py` | LightGBM / логрегрессия / Poisson-модели, смешивание ансамбля |
| `football_predictor/metrics.py` | RPS, log loss, Brier, точность, ECE |
| `football_predictor/cli.py` | командная строка |

> Это инструмент для анализа, а не гарантия выигрыша. Букмекерская маржа съедает
> небольшое преимущество, поэтому ставьте только при явном value и умеренным размером
> (в выводе указана 1/4 Келли).
